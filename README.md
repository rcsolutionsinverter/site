# RC Solutions - Sitio SEO Local

Sitio optimizado para GitHub Pages y SEO local en Ecuador.

URL objetivo: https://rcsolutionsinverter.github.io/site/

## Publicar

1. Sube todos los archivos a la raíz del repositorio.
2. En GitHub ve a Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: main.
5. Folder: / (root).
6. Guarda y espera el despliegue.

## Después de publicar

- Verifica la URL en Google Search Console.
- Envía el sitemap: https://rcsolutionsinverter.github.io/site/sitemap.xml
- Solicita indexación de la página principal.
- Crea/optimiza Google Business Profile con el mismo nombre, teléfono y ciudad.
