# RC Solutions - GitHub Pages

Sitio optimizado para GitHub Pages.

## Estructura

```text
/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── img/
│   └── imágenes del sitio
├── .nojekyll
└── README.md
```

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube todos los archivos de esta carpeta.
3. Ve a Settings > Pages.
4. En Source selecciona: Deploy from a branch.
5. En Branch selecciona: main.
6. En Folder selecciona: / (root).
7. Guarda los cambios.

GitHub Pages generará una URL similar a:

```text
https://tuusuario.github.io/nombre-del-repositorio/
```

## Nota

El sitio ya tiene el CSS, JavaScript e imágenes separados para que cargue mejor y sea más fácil de editar.
